# cafeteria-lanhouse 

# ☕ Website para Cafeteria & Lan House

Este repositório contém o código-fonte de uma aplicação web desenvolvida para apresentar o cardápio, os serviços de lan house e as informações de contato de um estabelecimento local.

---

## 🎯 Objetivo do Projeto

O principal objetivo deste projeto foi desenvolver uma interface web funcional, atrativa e responsiva para uma cafeteria e lan house, permitindo que clientes visualizem o cardápio digital, os preços dos serviços de internet e a localização do espaço. A aplicação busca resolver o problema da falta de presença digital do estabelecimento, facilitando o acesso às informações para novos clientes.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de todo o conteúdo das páginas.
* **CSS3:** Estilização visual, layout responsivo e design centrado na experiência do usuário (UX/UI).
* **JavaScript (ES6+):** Inclusão de interatividade básica na interface (como menus dinâmicos e validação simples de formulário de contato).

---

## 🧠 Aprendizados e Experiência

Durante o desenvolvimento deste projeto acadêmico, foi possível consolidar diversos conhecimentos fundamentais da Engenharia de Software e do desenvolvimento web:

* **Manipulação do DOM e Lógica no Front-end:** Compreensão prática de como o JavaScript interage com o HTML/CSS para criar páginas dinâmicas.
* **Design Responsivo:** Aplicação de conceitos de layout fluido e media queries para garantir boa navegação tanto em computadores quanto em dispositivos móveis.
* **Arquitetura e Organização de Código:** Estruturação limpa de pastas, arquivos de estilo e scripts, garantindo a manutenibilidade do código.
* **Resolução de Problemas:** Enfrentamento e correção de bugs reais durante a fase de estilização e renderização do layout.
